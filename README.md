## Installation
### Linux
Just download `/themes` folder and put `.toml` files in `~/.config/helix/themes/` (if those directory's do not exist then just create them)

for easier updates `git clone` this repository, copy needed theme or themes to `~/.config/helix/themes/` and `git pull` later as it updates (:J)
